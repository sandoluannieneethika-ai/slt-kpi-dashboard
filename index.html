Dashboard Amendment Register

All submitted amendment requests are displayed below.

Request Additional Data / Amendment

Use this area to submit requests for dashboard enhancements, KPI amendments, additional reporting requirements and new datasets.



Amendment Workflow

  1. Submit an amendment request using the button above.
  2. The request enters the queue as Waiting for Approval from Performance Team .
  3. Following approval, the request progresses to In Progress .
  4. Once development work has been completed, the request moves to Awaiting Sign Off from HD .
  5. Following approval and sign-off, the request is marked Completed .

Automatic Notifications

Email notifications are automatically issued whenever a request changes status.

  • Waiting for Approval from Performance Team
  • In Progress
  • Awaiting Sign Off from HD
  • Completed

Notifications are automatically sent to the recipients selected within the amendment request.
